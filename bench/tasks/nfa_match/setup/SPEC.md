# Tiny regex, full-string match

`fullmatch(pattern, text) -> bool` is true iff the **entire** `text` is
generated by `pattern`. Both arguments are `str`.

## Syntax

```
expr   ::= term ("|" term)*
term   ::= factor+ | ε          # empty term is allowed (it matches "")
factor ::= atom quant?
atom   ::= "." | "\\" any | literal | "(" expr ")"
quant  ::= "*" | "+" | "?"
```

- `.` matches any single character **except** newline (`\n`).
- A backslash followed by any character matches that character literally.
  A trailing backslash is a `ValueError`.
- `*`, `+`, `?` are greedy in the usual sense; because this is a boolean
  full-match they must not change which strings match, only that the engine
  actually implements them.
- `|` is alternation, lowest precedence.
- Unmatched `(`, unmatched `)`, or a quantifier with no atom (`*` at the
  start of a term, `|*`, `?*`) is a `ValueError`.
- A `+` or `*` or `?` immediately after another quantifier (`a**`) is a
  `ValueError`.
- Every other character is a literal, including space.

An empty pattern matches only the empty text.

## Constraint

Implement the matcher yourself. You may not import `re`, `regex`,
`fnmatch`, or `pathlib`.
