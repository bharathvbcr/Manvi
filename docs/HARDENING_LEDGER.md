# Hardening Ledger & Defect Catalogue

MANVI enforces a strict engineering philosophy:
- **Fix the class, not the case**: Root causes are resolved at the canonical owner layer.
- **Fail closed and loud**: Ambiguous inputs, malformed responses, or corrupt coverage files produce explicit failures, never silent passes.
- **Assert invariants byte-for-byte**: Model-visible prompts and session logs are verified before every LLM stream.
- **Every fix ships with regression tests**: Every hardened invariant is backed by automated adversarial unit and integration tests.

## Audit Pass `audit/command-write-differential` (2026-08)

Every row here was found the same way, and it is a way the passes above did not
use. The earlier command-gate work asserted verdicts against expectations
someone wrote down; these were found by executing each command line under
`sh -c` in a throwaway tree and comparing the files that appeared against the
gate's own verdict on those files. A hand-written expectation cannot catch a
case nobody thought to write down — the gate refused `echo x > .env` and
allowed `echo $(echo x > .env)`, and both answers matched their fixtures.

The invariant now stated and tested is: **the gate's verdict on a command line
is never more permissive than its verdict on the files that command writes.**

Two harnesses assert it. `gate/redirect_test.go` runs a hand-written corpus of
the shapes a redirection can hide in. `gate/redirect_generative_test.go`
assembles command lines from a closed vocabulary — harmless builtins, a fixed
set of relative targets, and the shell's own operators — so what varies is the
syntax the gate must read and never what the command can do; it is the one that
found the escaping-write case above. `MANVI_GATE_SOAK=N` raises its case count;
6,000 lines have been run against the fixed gate with the invariant holding, and
the same soak fails within the first few dozen lines against the unfixed one.

| Defect Pattern | Failure Mode & Consequence | Resolution & Hardened Invariant | Verified In |
|---|---|---|---|
| **Redirects Inside Command Substitutions Never Reached the Write Gate** | `RedirectTargets` stepped over `$( )`, backtick, `<( )` and `>( )` spans, so `echo $(echo x > .env)` reported no targets at all. The ladder recursed into those spans to judge what *ran* there; nothing judged what they *wrote*. Under every posture, including strict, the write landed and the secret rung never fired — and the same gap defeated the **outside-root** rung, so `echo $(printf x >> ../../anything)` was an arbitrary write anywhere the process could reach, not merely a write to one known-sensitive name. The escaping case was found by the generated differential, not by the hand-written corpus. | `RedirectTargets` descends into live substitutions to the same depth bound the ladder judges them at, unioning each span's targets with the clause's own. Failures below the top level become opacity rather than errors, so an unreadable span refuses instead of reporting an empty target list. | `gate/redirect_test.go`, `FuzzRedirectTargetsSeesInsideEverySubstitution` |
