# MANVI v0.0.4

This local release consolidates the DevMap host module and both pending dependency
branches. Host configuration rejects typed nil modules and catches configuration
panics before accepting requests. Advanced DevMap results retain nested
completeness validation, validate snapshot identity and token accounting, and
use the versioned readiness contract.

The installed binary is stamped with v0.0.4 through the existing release build
flag and records its Git revision. Publication of cross-platform release assets
is separate from this local installation.

This release consumes the hardened DevMap 0.1.1 kernel through the existing
process interface. Set `MANVI_MAP_BINARY` for an explicit executable; otherwise
the CLI resolves `devmap` on PATH before checking development build directories.
After replacing an analyzer build, rebuild the repository index: matching
release numbers alone do not prove the stored extraction payload is current.

The installed companion binaries are DevCouncil's `dcstore`, `dcverify` and
`dcgrep` 0.1.1. The Rust crates under `crates/` remain development fallbacks;
they are not linked into MANVI's Go executable. Restart an existing MANVI
sidecar to load a replacement executable and its current tool configuration.
