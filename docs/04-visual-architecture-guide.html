1. The Dual-Plane Architecture

MANVI splits work cleanly on the axis of IO-bound concurrency vs CPU-bound determinism. Go drives goroutines, providers, and terminals with zero CGO; Rust provides zero-allocation diff parsing, coverage analysis, and ACID SQLite locking.

Go Execution Plane

Concurrency & Interaction

Pure Go static binary (CGO_ENABLED=0). Zero external dependencies in go.mod.

  • manvi/agent Turn/step state machine
  • manvi/llm Anthropic, Gemini, xAI stream
  • manvi/gate 5-tier policy composition
  • manvi/grants Human & agent override ledger
  • manvi/ui/tui Elm-loop fullscreen terminal
  • manvi/session Immutable session.jsonl
Rust Analysis Plane

Deterministic Analysis

High-performance native utilities invoked over JSON stdio child processes.

  • crates/dc-store SQLite task lease mutex
  • crates/dc-verify Diff parser & rigor gates
  • crates/dc-verify Go & LCOV coverage bitsets
  • crates/dc-glob CPython fnmatch glob engine
  • devmap AST code graph & adjacency
Process Boundary, Not CGO

Go execs dcstore and dcverify passing arguments and JSON over pipes. Mutexes live in SQLite's partial unique index, not in Go memory. A crash in Rust never corrupts Go memory.

2. The Five-Tier Policy Ladder

Blocks are overridable when appropriate, but never invisible. A check that did not run records that fact, and a grant that cleared a write is explicitly branded on the tool output.

1
Workspace Boundary Check

Refuses any file write or command that escapes the repository root.

path.outside_root
2
Hard Security Rules (Ungrantable)

Secret paths, .git directory internals, and git force pushes can never be bypassed by any grant or posture.

path.credential (.env, *.pem) path.git_internal (.git/*) cmd.git.force_push cmd.git.bypass (--no-verify)
3
Soft Scope & Adjacency Rules

Evaluates whether changes match declared task planned files or resolved code-graph neighbors.

scope.unplanned scope.neighbourhood
4
Grants Ledger Consultation

Checks if an active, unexpired Human or Agent grant with valid justification exists.

5
Posture Demotion & Operator Escalation

Under dev/yolo, soft rules demote with warnings. Under strict in TUI, escalates to interactive modal.

4. Evidence-Driven Turn Lifecycle

The agent loop terminates on tangible evidence, not model declaration. History is always projected from the immutable session.jsonl disk log.

Stage Component Guarantee & Invariant
1. History Projection session.Project() Messages projected fresh from session.jsonl; in-memory drift is impossible.
2. Pre-Step Waterfall bus.PreStep Allows context compaction, pruning, or step rejection before token expenditure.
3. Streaming Provider llm.Stream() Separates reasoning from text; records delta and token usage in real time.
4. Tool Execution tools.Execute() Passes through Write/Command gate; logs input, output, and qualification status.
5. Termination Evidence agent.TurnStopping Loop terminates when model emits 0 tool calls, hits step limit, or passes serial checks.

5. SQLite Task Lease Concurrency

Multi-agent concurrency is enforced at the database level via SQLite's partial unique index:

CREATE UNIQUE INDEX ux_task_leases_active ON task_leases (task_id) WHERE status = 'active';

When sub-agent trees are cancelled (e.g. user presses Ctrl+C), MANVI invokes dcstore release using a fresh uncancelled context, ensuring task locks are immediately freed for subsequent turns.
